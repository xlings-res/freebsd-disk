# freebsd-disk

The FreeBSD 14.5-RELEASE boot disk (x86_64 qcow2, zstd-compressed clusters, serial console) that a virtual-machine runner boots. Upstream: The FreeBSD Project 14.5-RELEASE, installed from the official installer disc. The runner entry lives in mcpplibs/openkal-freebsd (tools/vm-runner); the recipe in the package index (`pkgs/f/freebsd-disk.lua`).
